# Random Dice Game

A two-player dice game in vanilla JavaScript. Every page load rolls two dice and announces the winner.

**[▶ Play it live](https://shzunknown11.github.io/RandomDiceGame/)** (refresh to roll again)

## How it works

- `Math.random()` picks a number from 1 to 6 for each player.
- The matching dice image is swapped in by changing the `src` of each `<img>`.
- The heading shows `Player 1 Wins!`, `Player 2 Wins!` or `Draw!`.

No dependencies: `index.html`, `index.js`, `styles.css` and six dice images.

## Run locally

Clone the repo and open `index.html` in a browser.

## What I practised

Random numbers, DOM selection and changing attributes and text from JavaScript.
